# 30 秒 UI 进化宣传片（纯代码生成）

一支为抖音制作的竖屏短视频：**同一个音乐播放器 UI**，从毛坯线框开始，随 8 个设计参数依次拨动，**累积式**进化为精致的玻璃质感成品——不是切换到别的 UI，而是从基础一路长成复杂。

全程零实拍、零第三方素材：HTML/CSS/JS 确定性动画（`window.seek(t)` 纯函数驱动）+ Playwright 逐帧渲染 1800 帧 + numpy 合成配乐 + ffmpeg 合成。

## 时间轴（8 层递进，层层累积不切换）

| 时段 | 拨动的参数 | 画面变化 |
|---|---|---|
| 0–2s | — | 毛坯线框 + 蓝色选框手柄（设计工具既视感） |
| 2–5s | 字重 / 间距 | 排版层级浮现，留白开始呼吸 |
| 5–8s | 色相 / 饱和度 | 灰度绽放为彩色，明暗基调反转 |
| 8–10.5s | 圆角 | 直角 → 大圆角 / 胶囊按钮 |
| 10.5–13.5s | 投影 | 多层柔和阴影，卡片浮起 |
| 13.5–16.5s | 模糊 | 玻璃拟态，极光背景从卡片后透出 |
| 16.5–19.5s | 动效 | 唱片旋转、均衡器跳动、进度推进 |
| 19.5–27s | （超越参数） | 粒子、扫光、光泽脉冲、视差 |
| 27–30s | — | 参数面板退场，成品定格 |

画面内除 UI 组件外仅出现**标准调节名**（字重、间距、色相、饱和度、圆角、投影、模糊、动效）及其数值，符合"纯 UI 展示"的约束。

## 技术要点

- **确定性渲染**：整支影片是关于 `t` 的纯函数，任意帧可独立复现（`seek(n/60)`），无 CSS transition/animation，粒子与抖动均由哈希种子驱动，保证多 worker 渲染帧间一致。
- **音频**：与画面阶段严格同步——每个参数激活对应一个上行五声音阶拨音，玻璃阶段进入 100 BPM 脉冲，富效果阶段叠加琶音与底鼓，结尾解决和弦收束；两遍 loudnorm 归一至 -16 LUFS。
- **色彩**：从亮灰画布点阵网格过渡到深色极光场景，主色 `#7F52FF` / `#00C2D1`。
